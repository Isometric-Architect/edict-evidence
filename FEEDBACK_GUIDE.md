# Optional feedback after a real use
No feedback is required for access or use. This sample does not transmit anything.
A useful voluntary report states the sample version, precise public tool/runtime version, agreed preservation requirement, relevant non-secret settings, and what happened with the bundled synthetic fixture. State whether the result is only self-reported or has a reproducible public example.
Do not attach customer data, production logs, file-system paths, account identifiers, tokens, proprietary workflows or hashes of private values. A hash can still expose a low-entropy value. Do not claim that a synthetic test proves production behavior.
A page view or download does not establish use. A matched example does not establish time saved. Silence is unknown, not failure. Reports are not independent merely because they use different accounts.

When the publisher enables repository Issues, a report can be posted there, but it is public. Do not post private material. A report is not automatically permission for reuse in a separate commercial dataset; the publisher will need a separately supported basis. Response times and custom troubleshooting are not promised. There is no automated reply or remote command execution from issue text.
